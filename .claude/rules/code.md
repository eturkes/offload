# offload code

- Law = `.agent/contract.md` (predicate ids C/P/R/S/L/Y/X/J/K); `Decisions` outrank it. A behavior change edits the predicate first; tests cite ids in names or comments.
- `internal/run/watch.bash` runs on both sides (local runs + inside `remote.bash` on pool hosts; remote = `<meta>/run-<sha>.bash`, installed by run.go's `boot`, X8) ⇒ bash-only, GNU coreutils/util-linux/procps, no controller paths. Every variable in watch.bash, remote.bash + boot is named `__…`: a bash local shadowing a caller-exported name is exported with the local's value, straight into CMD's environment (X2). `&` jobs in non-interactive bash get stdin `/dev/null` + ignored INT/QUIT ⇒ the explicit `<&0` and `trap - INT QUIT` stay. Guard = `TestScriptVariablesAreReserved` (static scan of the scripts + boot; fires on a planted `x=1`, `local plain`, `read -r -d "" zz`, `for dd in`); a new deliberate non-`__` name joins its allowlist with the reason.
- Deletion on a host = `remote.bash` `prune_one` (leaf files/symlinks under real-directory ancestors) + a linked worktree's own `rm -f .git` before its gitfile is written (Y4); rsync `--delete` only ever runs inside `.git` or `<meta>/repo` (a worktree's common dir; plain mode excepted, Y7). A new rsync flag that deletes or replaces outside those = a Y5 change.
- `internal/ctr/init.go` = PID 1 inside `offload ctr`'s container (`offload __ctr-init`, K8): it refuses to run unless `getpid() == 1`, since its teardown `kill(-1, TERM)` outside a pid namespace hits every process of the user. It drops forwarded signals arriving as signals via handlers (never `signal.Ignore`: SIG_IGN survives exec into CMD); signals reach CMD only over the control socket (fd 3). podman runs in its own session (`Setsid`), in its own transient scope where a user manager starts one (`podmanCommand`), without the caller's `INVOCATION_ID` (with it, podman keeps conmon in the caller's unit; CI runners are systemd services): podman dies on TERM (always a second, at times a first — X1's session pkill + scope kill), and a process group of its own would make it a terminal's stalled background job; the host's control socket end is nonblocking (`controlPair`) or readRecord's deadline is ignored. The binary is the init inside `FROM scratch`-style images ⇒ every build that ships it stays `CGO_ENABLED=0` (e2e TestMain builds static too).
- A shipped change → `tools/install` (one static build → controller + every pool host, sha256 per side must match): `offload ctr` on a host runs that host's installed binary, and `--check` reds on a differing one.
- Real-podman e2e (`test/e2e/ctr_test.go`) = one isolated vfs storage per package run (`CONTAINERS_STORAGE_CONF`, removed via `podman unshare rm -rf`), image `FROM scratch` + `ctrhelper` (`test/e2e/testdata/ctrhelper`, static) ⇒ no registry, the user's images untouched; the shared image is prebuilt by `offload ctr --layers` before parallel tests (a prebuild failure fails, never skips). No podman → skip; CI sets `OFFLOAD_REQUIRE_PODMAN=1`. Helper modes report readiness only after their signal setup (a TERM racing `signal.Ignore` kills them). Every podman sandbox goes through `podmanEnv`: its `$XDG_RUNTIME_DIR/libpod/tmp/pause.pid` links to the prebuild's pause process (killed at teardown) — a fresh runtime dir alone makes rootless podman start a pause process per sandbox that nothing reaps, or join through another test's `conmon.pid` (125 while that container is removed). e2e `TestMain` sets umask 022: fixture + checkout modes reach the image as root-owned copies the keep-id user must read + run (agent sessions on the controller run 077); unit fixtures set modes explicitly.
- e2e waits: readiness polls (`await`), completion waits, cleanup barriers + fixture-internal windows (a fake tool's rendezvous: a broken implementation still deadlocks + fails, later) claim no latency → `hang` (2 min; podman steps run 10-20× slower on a loaded host); a wait checking a promised latency (signal response, X1's 10 s, J4's 2 s, K7's 1 s, K8's `at once`) keeps its own bound. Stress check: the full gate beside `stress-ng --cpu 8` on the controller passes.
- Run log (J) = `internal/ledger`, driven by `runCommand`: `runLogged` owns every exit path and the wrapper writes the end record once ⇒ a new return path needs no logging call. A log failure never reaches the caller (J4): `write` notes it once on stderr and the run goes on, so exit status, output + placement never depend on the state dir. `runCommand` reads `signalStatus()` only after `ctx.Err() != nil`: `got` is written by the signal goroutine, and the cancel orders that read. e2e sandboxes set `XDG_STATE_HOME` ⇒ tests never write the real log; `runPair` (exact key sets per event) = the record-shape validator.
- Every ssh/rsync connection takes `remote.SSHOptions`; `test/e2e/testdata/ssh` refuses a call without them (rc 254) and honors `-n`, so the e2e suite checks X5 on every call.
- e2e fake hosts = dirs under `$OFFLOAD_FAKE_HOSTS/<host>` driven by marker files: `.probe` (probe answer), `.probe-hang` (probe sleeps 30 s), `.transport-fail` (every call but the probe 255: the host probes up, then each transfer or run fails), `.run-fail` (run-phase call 255; run phase = the boot command, matched on `sha256sum`), `.upload-fail` / `.download-fail` (rsync 23); each call logs `.ssh-call-<pid>`. A host without a dir = down.
- Mutation credit (not a gate step): `TMPDIR=/var/tmp/<name> .agent/tool mutago --workers=4 --timeout-coefficient=3 --logger-agentic-json ./internal/<pkg>/` in a disposable worktree (it rewrites sources in place; a killed mutant's test leaves its `t.TempDir` tree behind and a broken-root mutant can mirror `/` into it ⇒ TMPDIR on disk, outside any git repo — inside one, mirror's damaged-ancestor tests fail the baseline — deleted after; the default 10 s exec timeout is shorter than `internal/run`'s suite). mutago mutates only a file with a same-named `_test.go`: in the disposable worktree, add a stub `package <pkg>` test file per uncovered source (cli `ctr.go`; remote `ssh.go`). Unit-test escapes replay through e2e: coverage map = the e2e suite once with `OFFLOAD_E2E_COVERDIR=<dir>` (binary built `-cover`, one counter dir per sandbox) → `.agent/mutation/plan <agentic.json> <dir> <worktree> > plan.tsv` (each escape's covering tests; FULL = package-level line → the suite; NONE = never executed; container-only code — the init's `__ctr-init` dispatch — writes no counters ⇒ under-selected, rule those by hand) → push `ci/mutation` carrying `.agent/mutation/run/{agentic.json,plan.tsv}` (gitignored ⇒ `git add -f`) → `.github/workflows/mutation.yml` (20 shards of `.agent/mutation/replay`: patch, covering tests `-failfast`, a kill confirmed by its first failing test alone, revert; dedicated runners ⇒ no load flake passes for a kill) → artifacts `out-<n>`, then delete the branch. Survivor rulings (`new test`/`killed` naming their tests) → `.agent/mutation/verify <worktree> <table> <agentic.json> <out>` (red with the mutant, green clean). One targeted mutant at a time: `.agent/plant <worktree> <name> <file> <old> <new> <test-regex>` (applies, runs, reverts with `git checkout -- <file>` ⇒ commit the change under test inside the disposable worktree first, else the revert restores the old code). A mutant that hangs the suite reads as `rc … without a failing test`: bound the test instead.
